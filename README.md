# CTNLP

**亿方运维知识工程实验室（Yifang O&M Knowledge Engineering Lab）**
**项目：语文教学文本数据分析**

本仓库是实验室“语文教学文本数据分析”方向的项目仓库。围绕高中语文教材、课程标准必背篇目与考试文本，做三件事：

- **文本整理**：把散落在教材、课标与网络中的篇目整理为可检索、可复用的本地语料；
- **规律挖掘**：对用字、虚词、意象、相似度等做统计，回答“怎么记、怎么教”；
- **轻量 NLP**：词云、词频、TF-IDF、相似度等，用数据画像支撑教研与命题分析。

## 结论速览

- 必背 60 篇 = 课标 72 篇 − 12 篇选修文言文（文言文 20 + 诗词曲 40），正文共 **13194 字**。
- **“唯/惟”全库只有 13 处**（唯 5、惟 8，分布 11 篇）：非“只”义全部符合偏旁（口→语气、心→思/发语）；“只”义两字通用，按 **13 句封闭清单**背诵即可。
- 唐宋篇目占 65%；文言文与诗词曲呈两套话语体系（虚词/长句/天下 vs 月/江/风）；政论类文言文最“撞车”（《六国论》×《过秦论》相似度 0.069）。
